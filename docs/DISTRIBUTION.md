# Distribution Framework

A feature isn't complete until people can realistically discover it. This is the reusable checklist every interaction runs through before/at launch — fill in the template once per interaction, don't reinvent the channel list each time.

**Status note:** none of the 6 built interactions are in production yet (all live on the unmerged `feature/wag-match-quiz` branch, pending final review). The copy below is drafted and ready — nothing has actually been posted publicly. Publishing any of it (YouTube description edits, social posts, newsletter sends) requires Katie's explicit go-ahead, same as production deployment itself.

## The template (copy for each new interaction)

```
## <Interaction Name>
- Real URL: 
- One-line hook (what it is, why someone clicks):
- YouTube video description blurb (add to the most relevant existing/upcoming video):
- Pinned comment (short, casual, on-brand):
- YouTube Community post copy:
- Instagram caption (feed or Story):
- TikTok caption:
- Newsletter blurb (for the next WAG Insider send):
- Homepage placement: [confirmed live in Explore shelf / not yet]
- Related-article placement: [which real article(s) should link here]
- Podcast mention: [does an upcoming episode reference this on-air?]
- Backlink opportunity: [any real external site that could link in?]
- Data this generates worth turning into future content: [real % results become "X% of fans said..." posts once real votes exist]
```

## Worked example: WAG Match

- **Real URL:** thewagpodcast.com/match/
- **One-line hook:** 5 quick questions, find out if you're Angelina, Scarlett, or Annabella.
- **YouTube video description blurb:** "Take the real WAG Match quiz — find out which one of us you're most like: thewagpodcast.com/match/"
- **Pinned comment:** "ok but which one of us are YOU actually like 👀 take the quiz → thewagpodcast.com/match/"
- **Community post copy:** "We built a quiz. Are you an Angelina, a Scarlett, or an Annabella? Be honest 😏 [link]"
- **Instagram caption:** "Which WAG are you actually like? 5 questions, no cap. Link in bio → WAG Match"
- **TikTok caption:** "take this before you comment which one you think you are 👀 #WAGMatch"
- **Newsletter blurb:** "New: WAG Match. 5 questions, one real result — take it before we tell you who WE think you are."
- **Homepage placement:** confirmed live in the Explore shelf (Formats & Games, position 2) — see `src/pages/index.astro`.
- **Related-article placement:** each girl's own profile page on wildadventuregirls.com now links to it directly (added in the audit pass); `/hosts/` and `/guys-answer-questions/` also cross-link.
- **Podcast mention:** none scheduled yet — real opportunity to name-drop on an upcoming episode once this is live (e.g., "we made a quiz about us, go find out who you're most like").
- **Backlink opportunity:** none identified yet.
- **Data → future content:** once real votes accumulate, the most/least common result becomes a real, shareable stat ("most fans get Annabella" or whichever turns out true) — a real Short/Reel/Community-post asset, not invented.
