# WAG Podcast Growth Extension

**One executive question this module answers: what of the Growth OS actually applies to the podcast, and what's genuinely different?**

**Part of the WAG YouTube Growth Operating System.** This is deliberately NOT a second, parallel system — per the standing instruction, WAG Podcast gets the same loop (idea -> packaging -> hook -> structure -> publish -> clips -> website -> measure -> learn), with each stage marked shared or podcast-specific. Where a stage is shared, this doc points back to the source rather than repeating it.

---

## What's shared (use as-is, don't rebuild)

- `WAG_CHARACTER_BIBLE.md` — same three real people.
- `WAG_PATTERN_LIBRARY.md`'s Title/Thumbnail/Sponsor-Integration patterns — general enough to apply to either property.
- `WAG_VIDEO_GREENLIGHT.md`'s record shape and scorer — apply to podcast ideas using the same fields.
- `WAG_EXPERIMENT_REGISTRY.md`'s record shape.
- `WAG_MEASUREMENT_STANDARDS.md`'s *method* (not its specific numbers, which are channel-specific).
- The Shorts/clips mechanic — already real, already shared, already working.

## What's genuinely podcast-specific (don't force the long-form version onto it)

- The conversation-based structure (question -> real answer -> live follow-up -> honest wrap) — distinct from the 7-beat challenge/stunt structure.
- The real, separate content buckets (Guys Answer Questions, Dating/Relationships, Hot Takes, Guest interviews) — distinct from `WAG_CONTENT_BUCKETS.md`'s physical-format buckets.
- The publishing platform mix (YouTube + Spotify + Apple) and separate cadence.
- The website role — deliberately "why this conversation mattered," never duplicating the main site's "what happened" framing.

## Real, honest gaps this pass didn't close

1. **A formalized conversation-format structure** (the podcast's own equivalent of the 7-beat challenge structure) doesn't exist yet as a named framework — real, working practice exists (per Guys Answer Questions' own real success), but it hasn't been written up as its own Episode-Framework-Library-style catalog entry.
2. **A fresh, real `@WAGPodcast` Studio pull** for `WAG_MEASUREMENT_STANDARDS.md`-style thresholds — the existing CEO_COCKPIT.md figures are real but from 2026-08-05/08-08, not this pass's live pull.
