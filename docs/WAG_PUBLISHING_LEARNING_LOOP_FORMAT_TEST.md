## The elevated question

Not "which slime-book layout is nicest" — **"Have we discovered a repeatable WAG publishing experience that can become a defensible franchise and feed the larger WAG ecosystem?"** Everything below is built to answer that, not to pick a winner on vibes.

## Format D — the 4th hypothesis, built and added to the prototype set

Per Katie's instruction: Missions' progression architecture as dominant, carrying Format A's warmth/low cognitive overhead, with a mystery beat reserved for specific high-value moments (chapter openers only, explicitly labeled as rare in the spread itself) rather than a full case-file redesign. Built on the **same recipe as Format A** (Biggest Fluffy Slime), so this pair is the one true apples-to-apples comparison in the set — everything else varies both format and content. Not assumed to win. Real risk named on the page itself: could read as cluttered if the three elements don't stay disciplined.

## Test design — corrected 2026-08-15: small and high-quality, not formal market research

Per Katie's explicit correction: a small, high-quality test with specific questions beats a large panel that delays publishing. **Child engagement and parent purchasing stay separate instruments** (different business questions), but each is now a short, specific list — not an elaborate behavioral-observation protocol. Observe behavior, not just compliments, throughout.

### Kids (real target-age readers, not Bella alone)

Present the 4 mockups in randomized order, then ask, while watching what they actually do rather than only what they say:
1. What page would you look at first?
2. Which character do you like?
3. What do you want to try?
4. What was confusing?
5. Would you want another one?

### Parents (separate, asked without seeing the child's reactions first)

1. Would you buy this?
2. For what age?
3. What price feels reasonable?
4. Does it feel educational enough to justify purchase without feeling like school?
5. Would your child use the QR/digital experience?

No target respondent count is set — small and real beats large and slow. This is a decision-support test, not a published study.

## Wobbie — evaluated as potential recurring IP, not a page mascot

Separate from the format question. Real, evidence-based assessment: Wobbie already has a locked visual design (goggles, sewn patches making him plush-manufacturable, huggable proportions), a defined behavioral rule (reacts physically, never narrates — keeps him from becoming generic filler), and — per this session's real character/IP research (in progress) — the mechanisms that separate genuine licensable character IP from a flat mascot are largely already present in his existing spec: a visual signature independent of any one book, and enough personality rules to stay consistent across formats. **What's not yet tested:** whether he has enough independent presence to be wanted "even when a kid isn't doing a slime experiment" (Katie's own bar from the original Publishing directive) — this is exactly what the observation test's Wobbie-attachment dimension (#8 above) is designed to surface. The deeper character/IP research (rights structures, real precedent for one character crossing unrelated subject categories, licensing mechanics) is running now and will feed a full Creative Brief — this section records the format-level Wobbie signal only.

## Cross-category extensibility — does the mechanism travel, or is it slime-specific

| Format | Travels to Science/Animals/Experiments/Adventures? |
|---|---|
| A — Companion | Yes, cleanly — swap subject, keep Wobbie + girls' voice + one code per spread. Lowest re-engineering per future book. |
| B — Missions | Yes, and *strengthens* — a Lab Rank system can run as one unified progression across every future category, the strongest cross-book collectibility mechanic of the four. |
| C — Secret Files | Partially — the mechanic travels, but each new book needs a fully new mystery arc designed from scratch. Highest creative overhead per title. |
| D — Hybrid | Yes — inherits B's clean structural travel, with the mystery layer explicitly rare/reserved rather than needing a full new arc every book. |

## How this connects to the reusable Publishing pipeline (Books #2–5)

This IS the Concept→Market-Validation stage of the real Publishing pipeline (`WAG_SLIME_LAB_PUBLISHING_PLAN.md`'s stage-tracking table), running for real on Book #1 — not a side exercise. Whatever format wins becomes the **reusable spread template** for Books #2–5, which is the actual point: WAG isn't just finishing one book, it's learning how to produce the next four faster. The 14-element page structure, whichever collectibility mechanic wins, and Wobbie's role all become standing Publishing/IP infrastructure once validated here, not re-decided per future book.
