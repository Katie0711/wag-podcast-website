## 1. Who precisely is Book 1 for?

- **Core reader age:** 7–11, upper end of the age band still genuinely delighted by hands-on slime experiments — younger than WAG's core video audience, which is the normal pattern (a teen creator's activity/craft content typically pulls a younger sibling-adjacent audience, not a copy of the main viewer).
- **Reading level:** Early-to-middle elementary. Short paragraphs, simple sentences, strong visual/photo support so it works even for a reader below grade level — the low-friction-reading principle behind Dog Man and Wimpy Kid's reluctant-reader success.
- **Interest level:** Slime/DIY/hands-on kids; WAG's own existing younger-sibling and aspirational-viewer audience (kids who watch WAG Main and see the older girls as aspirational, not peer-age).
- **Independent reader vs. parent-child:** Primarily built to work **alone or with a friend** — the whole point of an activity format — but genuinely fine as a parent-child project for the messier recipes (Science Lab chapter). Recommendation, following Klutz's documented success pattern: write instructions **to the kid directly**, with safety/adult-supervision notes as a separate visual callout, not folded into the narrative voice.
- **Primary buyer:** A parent or gift-giver — a different person with different criteria than the reader, confirmed as the norm across every successful franchise studied (see §3).

## 2. What are the strongest current franchise/format mechanisms worth studying?

Cross-cutting findings from the research, already true of WAG's existing material more than a new build would suggest:

- **A visual/physical signature independent of plot** — identifiable from one page with the text covered. WAG already has this: Wobbie's locked design, the consistent spread layout.
- **A voice/structural device that stays constant while content changes** — the mechanism that lets a format scale to many volumes without feeling repetitive. WAG already has this: the 14-element page structure, the girls' real transcript-sourced banter pattern.
- **An active participation mechanic**, not passive reading — WAG already has this: the Secret Slime Code, with real precedent in actual footage.
- **Distinct, separately-satisfied psychology for the child reader and the adult buyer** — present in every successful example studied (Who Would Win = spectacle for the kid / "builds knowledge" for the parent; Klutz = fun craft for the kid / zero-failure-risk completeness for the parent). **WAG does not yet have an explicit version of this** — see §3.
- **A named, documented failure mode to avoid**: dependence on external, maintainable infrastructure as a *required* part of the experience (39 Clues' optional game layer survived; Infinity Ring/Spirit Animals' required app layer is now permanently lost). Directly supports Katie's own instruction that the physical book must be satisfying and complete without any digital participation.

## 3. What should the proprietary WAG Book Formula try to accomplish?

WAG's book sits structurally closer to the **Klutz/Ology "activity/experience" family** than the **Wimpy Kid "narrative-humor" family** — there's no ongoing story arc, each spread is a self-contained experience. The Formula should borrow narrative *texture* (Wobbie's voice, the girls' banter, the Secret Slime Code mystery) the way Ology borrows tactile delight, without pretending to be a story-driven book it isn't.

**Recommended weighting** (per Katie's own instruction not to build a kitchen sink):

| Weight | Element | Why |
|---|---|---|
| **Dominant** | Experiment/Action + Personality/Humor | You're doing real slime science *with* Wobbie and the real WAG girls — the actual, already-proven promise |
| **Strong supporting** | Mystery/Secret | The Secret Slime Code — real precedent, real participation mechanic, genuine series-anticipation potential |
| **Light supporting** | Real Learning, Collectible | "Why It Works" stays a real but secondary box, not the headline; a light collectibility layer (badges/stamps, §5 below) is worth adding — not yet present in the real material |
| **Minimal by design** | Story/narrative arc | Appropriate for this format — forcing a plot would fight the activity-book structure that already works |
| **Present but never required** | Digital Continuation | Real, additive, must never gate the book's own completeness — matches Katie's explicit instruction and the 39-Clues-vs-Infinity-Ring finding |
| **Untested, worth prototyping** | Mission/Challenge framing | Reframing "make this recipe" as "complete this WAG Lab mission" is a cheap addition that could sharpen participation and stakes — this is Prototype 2 below |

## 4. Three materially different prototype directions

All three reuse the same real, already-proven assets (Wobbie, the girls' real voice, the 14-element structure, the Secret Slime Code) — none require new content creation to prototype, only re-framing of what already exists.

### Prototype 1 — "WAG Lab Companion" (evolutionary, lowest risk)

The already-proven system, sharpened. Wobbie as the ever-present lab companion (reacts, never narrates — already the rule in the voice guide); the girls' real banter as the entertainment layer; one Secret Slime Code puzzle per spread building toward an end-of-book reveal. **Dominant promise:** "Make real slime with Wobbie and the WAG girls guiding you — and crack the code as you go." De-risked, since it's already proven at the individual-spread level.

### Prototype 2 — "WAG Lab Missions" (mission/challenge-led)

Every recipe becomes a numbered Mission with a stated goal and a Lab Rank (Trainee → Explorer → Master), paying off with a real completion moment (a badge, a stamp) — this is where a genuine collectibility architecture enters (§5 below), borrowing Klutz's zero-failure-risk-completeness principle directly. The Secret Slime Code becomes "Mission Intel," unlocked per completed mission. **Dominant promise:** "Become a WAG Lab Explorer — complete missions, earn your rank." Real risk: mission-framing could crowd out the girls' natural banter if overdone — needs careful balance, not a wholesale rewrite of the voice.

### Prototype 3 — "The Secret Slime Files" (mystery-led, highest novelty)

The mystery becomes the *primary* promise, not a light garnish: the book is framed as a case file the reader solves alongside the girls and Wobbie. Recipes become evidence/clues; "Why It Works" becomes "lab analysis"; codes accumulate across the whole book into one real payoff at the end (a hidden final message, a bonus recipe, an invitation to a "next case"). **Dominant promise:** "Solve the Secret Slime Files with the WAG girls." Highest differentiation from existing comp titles (none of the real slime-book comps found in market research use a mystery layer) — also the riskiest: the case-file framing has to feel integral to the recipes, not pasted on top, or it reads as gimmicky.

**None of these require full manuscripts to test** — one representative mockup spread per direction, adapted from material that already exists (the real Biggest Fluffy Slime / Gummy Bear Slime / Glow-in-the-Dark Snow Cone Slime sample spreads), is enough for a real test (§6).

## 5. What recurring character/world architecture should we test? — the aging-problem comparison

Katie's own flagged addition, given the fullest comparison, not a decision:

| Architecture | Longevity | Authenticity | Audience connection | Flexibility | Licensing potential | Future expansion |
|---|---|---|---|---|---|---|
| **A. Real girls as themselves** | Low — every book ties to a specific real-world era; the girls will grow up and may eventually leave the brand | Highest — maximum real-voice connection | High — existing fans see "their" girls directly | Low — every future book needs new real photography/scheduling | Low — hard to license likeness-anchored IP without the real people's ongoing involvement | Weak — animation/merch built on real minors' likenesses is legally/ethically complex in ways illustrated IP isn't |
| **B. Illustrated/stylized WAG versions** | Medium-high — drawn at a consistent "eternal" age, insulated from real aging | High — still recognizably the girls | High | Medium — one illustration commission unlocks many future books, but design still tracks the real girls' evolving brand | Medium — more licensable than real likeness, but still conceptually tied to 3 specific real people | Medium-strong — animation/merch-ready, but entanglement with the real girls' choices remains |
| **C. Fictionalized WAG universe, inspired by real personalities** | High — a wholly fictional trio can run indefinitely, recast or reimagined | Medium — inspired by the real sensory-narrator/dare-taker/reactor-jokester dynamic already documented in real transcripts, but explicitly not literally "the girls" | Medium — fans may recognize the personality types, one step removed from watching the real girls | High — fully author-controlled | High — wholly-owned fictional IP, no real-person entanglement | Strongest of the fully-independent options — same category as Dog Man/Wimpy Kid |
| **D. Original character(s) + girls as guides** | High for the character (Wobbie doesn't age); medium-high for the girls' voice layer, which can be refreshed without redrawing anything | High — the girls' real voice is preserved exactly as it already works today: banter/narration, not static portraiture | High — real WAG-girl voice *and* a new ownable character to attach to | High — Wobbie's design is already locked; adjusting the girls' voice contribution in future books is a content decision, not a redesign | High — a wholly-ownable, non-human mascot, fully independent of the real girls' future choices, plush/sticker/merch-ready | Strongest option that still preserves the real-voice differentiator |

**Recommendation, not a decision:** **D is the strongest fit**, mainly because it isn't actually a new choice — it's already what the proven sample spreads and Wobbie's locked design do today. It solves the aging problem most cleanly (the mascot doesn't age; the girls' voice doesn't visually age either, since it's text/banter, not portraiture), and it's the most licensing/expansion-friendly option that keeps the authentic-voice differentiator this material's own evidence identifies as its real edge. **B is the strongest alternative**, and not mutually exclusive with D — an illustrated-girls treatment could live on the cover alone while D governs the interior, rather than forcing an all-or-nothing choice.

## 6. How do we test the prototypes with real kids and parents?

Per Katie's own instruction: observe behavior, not just ask "do you like it."

1. Build one real mockup spread per prototype (3 total) — cheap, since each adapts an already-drafted real sample spread into the new framing, not new content.
2. Test with a small real panel — Bella (already documented as responding well to Wobbie's direction) plus a few real peers/cousins in the 7–11 band, and their parents, in a real low-stakes session — not a survey.
3. Observe: which mockup gets picked up first, where reading starts/stops, what gets skipped, where the laugh happens, whether the recipe actually gets attempted, whether the Secret Slime Code gets noticed and engaged, what's remembered the next day, what parents flag about value or safety.
4. The single sharpest real signal, in Katie's own words: **"When can I get the next one?"**
