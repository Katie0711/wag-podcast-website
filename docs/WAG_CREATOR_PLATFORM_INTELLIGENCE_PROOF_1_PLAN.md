## Search-first, not filter-first

The Director runs targeted searches directly against WAG-relevant terms (teen girl cast, female ensemble adventure/comedy, video podcast for teens, Shorts-to-long-form pivot, etc.) to build an initial candidate list **before** any generic leaderboard is consulted. A ranking list may still appear as one input among several, but only after the relevance-first candidate list already exists — the reverse of Proof 0's order.

**Bounded scope:** 8–12 targeted discovery queries, not exhaustive coverage of all 11 categories. Screen results to a relevance-scored shortlist, then apply the novelty pre-check below before selecting the final 3–5 for full investigation — same bounded size as Proof 0.

## Ingestion integrity applies here too

Every numeric/structured claim surfaced during discovery goes through the gate built after Proof 0 (`WAG_CREATOR_PLATFORM_INTELLIGENCE_PROOF_0.md` §13): raw text over LLM paraphrase for anything tabular, deterministic parsing for rank/views/percentages/dates, raw source text preserved, `ingestion_validated=false` blocks promotion to the expensive chain until independently verified.

## Novelty pre-check — before the expensive chain, not after

For each shortlisted candidate, query WAG Brain (`canonical_facts`, `predictions`, `outcomes`, `raw_observations`) for related prior evidence *before* running the full 9-stage chain. Candidates that are fully **KNOWN TO WAG** with nothing new to add are filtered out here — this is what keeps the expensive chain from being spent re-discovering what's already sitting in WAG Brain. Candidates that would land as **CONTRADICTS EXISTING WAG BELIEF** or **NEW EVIDENCE FOR EXISTING BELIEF** still proceed; both carry real value even when prior evidence exists.

## The evidence chain — mandatory, in order, on every surviving candidate

A finding only reaches Katie if it survives all nine stages:

1. **SIGNAL** — what was found, source, source tier
2. **VERIFIED DATA** — passed the ingestion-integrity gate; no unvalidated numeric claim
3. **WHY IT MATTERS** — explicit connection to a real WAG strategic question, not just "this is popular"
4. **PRE-BREAKOUT RECONSTRUCTION** — same 30/60/90/180-day method as Proof 0, mandatory
5. **NEGATIVE EVIDENCE** — actively search for a comparable case that didn't work
6. **WAG HISTORY COLLISION** — query `canonical_facts`/`predictions`/`outcomes` for prior related WAG evidence (this is also where the novelty label gets assigned, formally)
7. **WAG ADVANTAGE** — Yes / No / Potential, with reasoning
8. **AUDIENCE RELEVANCE** — does this genuinely fit WAG's actual demographic/content boundaries (informal today pending the real Audience Intelligence department, but not skippable)
9. **ACTION/TEST** — exactly one of: film this / test this packaging mechanism / change this production practice / test this Shorts strategy / investigate this audience behavior / build this capability / watch this development / **do nothing**. Never forced into "make a video" — Proof 0's honest "no forced third test" is the standard, not the exception.

## Novelty labeling — mandatory on every promoted finding

Determined at stage 6, not asserted casually:

- **NEW EVIDENCE FOR EXISTING BELIEF**
