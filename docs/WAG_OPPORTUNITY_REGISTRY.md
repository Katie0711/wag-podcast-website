## The sequencing rule this registry protects

Real WAG problem → repeated workflow → documented system → internal tool → measurable value → reusable playbook → membership/product test → only then commercial software, if ever justified. This registry exists to make sure that sequence isn't skipped — an opportunity earns its way down this list through evidence, not through sounding exciting.
