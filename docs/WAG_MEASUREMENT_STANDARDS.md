# WAG Measurement Standards

**One executive question this module answers: did it actually work?**

**Part of the WAG YouTube Growth Operating System.** Every number below is a real, live pull from `@TheWildAdventureGirls`' own YouTube Studio, taken 2026-08-09 — not borrowed from MrBeast, Ryan Trahan, or any other creator studied in `WAG_PATTERN_LIBRARY.md`. Those creators' numbers describe channels at a completely different scale and would set thresholds WAG could never realistically hit or would clear too easily to mean anything. **Thresholds below are WAG-specific, by design.**

**Honest scope of this pass:** YouTube Studio's simplified analytics view (used this pass) surfaces views, watch time, subscriber delta, revenue, average view duration, average percentage viewed, and traffic-source breakdown cleanly. It does **not** surface per-video CTR% or a first-30-second/1-minute retention-curve breakdown without switching into a deeper report-building flow that wasn't completed this pass. Those two fields are flagged as real, specific gaps below rather than estimated or borrowed from anyone else's numbers.

## Working WAG-specific thresholds (from the real data above, not borrowed)

**Stated with the same honesty discipline as `WAG_VIDEO_GREENLIGHT.md`'s scoring system: this is pattern-matching against a small, real, honestly-sized dataset, not a statistical guarantee.** Treat these as working baselines to refine as more real data accumulates, not fixed rules.

- **Normal (long-form):** roughly 4K-12K views in the weeks after publish, per the channel's own real "typical performance" range shown by Studio for a recent video.
- **Strong:** clearing that typical range meaningfully — the real worked example above (20.5K vs. a 4K-12K typical range) is a real strong performer, not a breakout.
- **Breakout (recent, fast):** 20K+ views within 48 hours of publish, per the real top-content comparison above — this is a fast, early signal, distinct from a video that slowly accumulates views over weeks.
- **Warning:** a 28-day channel-wide views figure meaningfully below the channel's own real typical range (as seen in the channel-level table above) — but always cross-check watch time and subscriber delta in the same window before treating a views dip alone as a real problem, per the honest mixed-signal read above.
- **Shorts normal:** the real engagement split (roughly two-thirds stay to watch, one-third swipe away) is this channel's real current baseline — a Short performing meaningfully worse than that split on stay-to-watch is a real, worth-investigating signal.

## Corrections and new findings from the 2026-08-09 forensic research pass

**A third-party SEO/keyword score does not reliably predict WAG's real outcomes — confirmed, don't rely on it alone.** vidIQ's real, observed "SEO/Keyword Score" scored WAG's own real #1 all-time video ("Beginner vs. Experienced Horse Owners! *OUT OF CONTROL*," 2,812,946 views) only 30/100 ("LOW"), while several much lower-performing videos scored similarly or higher. Real, direct evidence: treat this specific tool as directional at best for WAG, never causal. Its own underlying methodology was not independently verified.

**A real, unresolved runtime confound — flagged honestly, not adjudicated.** WAG's real all-time #1 video is only 5:48 long; the current content era has shifted to 33-43 minute uploads. Whether the shorter historical top performer suggests runtime itself suppresses reach, or whether newer, longer uploads simply haven't had as long to accumulate views, **cannot be separated with the data available.** This is a real, deliberate WAG-side test candidate — see `WAG_EXPERIMENT_REGISTRY.md`.

**A real, newly-discovered audience segment: a longitudinal "Epic" legacy layer.** Real comments on a brand-new 2026 upload reference watching WAG years ago on Epic (a schools/kids reading-and-video platform) and are "so happy to see you guys all grown." This is a real, distinctive asset no existing WAG doc previously named: a longitudinal audience that aged up alongside the girls, not a cold audience being acquired fresh. Worth factoring into future audience-facing copy and community strategy.

**Real, already-active Community-layer behaviors exist — the prior "Community tab absent" finding in `WAG_PATTERN_LIBRARY.md` describes the native Community tab specifically, not WAG's comment-section engagement, which is real and active.** Directly observed: a real "best comment gets pinned" incentive run by the WAG team, and at least one real instance of the team asking its own audience a direct content-direction question in a comment ("who is loving this horse vids and who would like other kinds of vids?"). Real, repeatable, low-cost tactics — keep doing them deliberately.

## Honest, explicit gap list

1. **Per-video CTR%** — not surfaced by the simplified Studio view used this pass; needs a follow-up pull using Studio's Advanced-mode report builder (the `VIDEO_THUMBNAIL_IMPRESSIONS_VTR` metric exists in Studio's own data model, confirmed by URL inspection this session, just not rendered as a simple number in the flow used here).
2. **First-30-second and 1-minute retention-curve breakdown** — Studio shows "Average percentage viewed" as one real number (23.4% in the worked example) but the actual retention *curve* (where in the video viewers actually drop off) needs the "Audience retention" chart read directly, not just the summary stat — flagged as a real, specific next step rather than estimated.
3. **Views at fixed real intervals (1hr/24hr/7day) for a single video** — the real data pulled this pass used Studio's own "since published" and "last 28 days" windows, not custom 1hr/24hr/7day cut points specifically; a future pull could build that exact view using Studio's date-range picker on a freshly-published video.
